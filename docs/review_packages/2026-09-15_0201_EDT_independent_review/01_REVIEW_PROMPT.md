# 给独立 Review AI 的提示词

请作为一位此前不了解本项目的独立ICASSP论文审稿人，审阅我提供的当前稿件。目标是判断论文的科学论证、可读性、图表表达和证据边界，并核对老师此前提出的revision要求是否真正落实。

主稿件：`manuscript/current_paper.pdf`（原文件名ICASSP_2026_acoustic_disease (29).pdf）。源码、图件、老师反馈及实验摘要是辅助材料。不要使用其他写作AI的memory、聊天记录或私下解释来替论文补充论证。不要预设论文应被接受或拒绝，也不要因为老师曾严厉批评旧稿就沿用旧结论。

## 第一轮：先按陌生读者阅读主PDF

在阅读老师反馈前，先形成以下判断：

1. 用自己的话说明：论文研究什么问题，具体gap是什么，方法如何回应，主要贡献是什么，哪些实验支持这些主张。
2. 判断Introduction、Datasets、Method、Evaluation和Conclusion是否形成连续论证。特别看每段为什么出现、段落结论如何推进下一段、术语和比较对象是否一致。
3. 分别用一句话说出Figure 1、Figure 2、Table 1、Table 2的takeaway；如果不能仅凭图表及caption说清楚，指出具体缺少什么。
4. 判断baseline是什么、哪些参数被训练、数据分别用于什么训练/评测，以及各列结果能否公平比较。不要把有引用的encoder名称自动当作完整既有方法的复现。
5. 检查方法符号、表示维度、监督来源、损失、任务读出与图是否对应；检查结论是否超出实验、数据和标签所支持的范围。
6. 查看真实PDF排版：正文目标是4页，参考文献可另页。判断是否有正文跨页、图中文字过小、表格拥挤、阅读顺序受浮动体影响等问题。不要仅从纯文本推断视觉问题。

## 第二轮：再核对老师的revision建议

阅读`02_ADVISOR_REVISION_BRIEF.md`，必要时查`source_feedback/`中的原始记录，按R01–R12逐项判断当前PDF是“已解决 / 部分解决 / 未解决 / 材料不足”。

必须区分：
- 老师针对旧稿的历史评价；
- 老师提出的修改建议；
- 当前PDF实际写出的内容；
- 你独立发现的新问题。

老师反馈中的示例和假设也需要事实支持。例如，不要直接把“所有已有方法都劳动密集”“我们完全不需要标签映射”写成事实。如果建议不能被现有方法或文献支撑，请说明应怎样保留其写作目的而修正具体主张。辅助材料解释了某个概念，不等于正文已经解释清楚。

## 输出格式

A. 整体判断：简短说明当前主张能否读懂、最有价值的部分是什么、最大风险是什么；不要给凭空精确的接收概率。

B. 优先问题表：主清单最多8项，每项包含：
- 优先级：P0（影响核心理解或科学结论）、P1（影响说服力/清晰度）、P2（润色）；
- PDF页码、section、图/表编号；必要时补源码文件与行号；
- 一小段当前原文或可定位的图表元素；
- 具体问题及其影响；
- 最小可执行修改建议；
- 需要“文字修改 / 利用已有结果重组织 / 补核来源 / 确实新增实验”中的哪种工作。
不要为凑数量制造问题，不把未经核实的怀疑写成确定错误。

C. 老师建议落实矩阵：R01–R12逐项给状态、当前证据和剩余修改，不只复述原反馈。

D. 最小修订顺序：给出优先解决的3–5步；同时提出将全部正文收进4页的具体删减或图表空间取舍。优先改善信息组织，不只建议缩小字号、边距或压缩行距。

E. 对最关键的2–3处文字问题，可以给简短英文替换示例；不要直接重写整篇，也不要引入未经验证的新claim。

## 证据与执行要求

- 结论以当前PDF为主。源码若存在更新差异，列出差异，不混用两个版本。
- 可在第二轮按需查`03_REVIEW_CONTEXT.md`及`optional_evidence/`；这些材料不是作者可以省略正文说明的理由。
- 检查已有多标签学习、异构标注学习与本文的具体区别。若联网核实文献或代码，优先原论文和官方仓库并给链接；未能核实的事实写“待核实”，不要凭印象断言没有先例或没有公开代码。
- 将任务相关的共享声学预测与“已证明特征域不变/完整还原所有原生标签”等更强主张区分开。相同来源的数据、共同属性和原生终点也不能不加定义就混称同一任务。
- 对统计、选模和数据使用提出与claim相称的检查。不要把建议新增的实验描述成现有实验已经失败；缺少原始产物只能说明本包无法独立核验，不能直接断言数值有误。
- 只做审阅。可读取给出的PDF、图件和文本；不编译LaTeX、不改文件、不跑训练/推理、不替我联系任何人。
- 不添加或恢复DONE/\revisiondone标记。
- 默认用中文分析，英文替换示例保留英文。先报告科学与逻辑问题，再处理语言细节。
