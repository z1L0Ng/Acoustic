## 2. 09-04 短会对论文主线的要求

老师关注的 contribution 是“研究发现了什么”或“方法使什么成为可能”，不只是 classifier、ablation、native metrics 或准备放进图表的内容。每条候选 contribution 需要明确：

1. 具体的发现或能力是什么；
2. 它的价值是什么，literature 已经做到或观察到多少；
3. 哪些结果支持它，以及没有本方法或采用 matched alternative 时会怎样；
4. 证据允许声称的范围和仍缺的对照。

现阶段按以下方向提炼，不把候选表述直接写成已证实的结论：

| 候选价值方向 | 要回答的问题 | 现有证据与限制 |
|---|---|---|
| Gap identification | 文献是否已清楚揭示同类跨数据集失效？我们的 baseline 实验额外识别了什么？ | 已有固定 checkpoint transfer；需要核对相同 task/unit/selection 下的 prior art，不直接声称 first |
| Method-enabled capability | 方法使一个模型能处理哪些以前难以共同处理的 native tasks / label availability？相对 independent heads 或 single-dataset 模型增加了什么？ | 当前有两 core datasets 的 joint benchmark；方法优势仍需 matched controls，不能由组件存在本身证明 |
| 可重复的经验发现 | 结果是否揭示了有价值的 retention / trade-off 或适用边界？ | 可从 native metrics、Sp/Se、per-class 与 bounded diagnostics 提炼；不预设必须形成第三条 contribution |

需要特别区分：

- 固定 source head 的 transfer 受限，不自动等于其 learned features 不可迁移；fixed-head transfer 与训练 target-native head 的 representation adaptation 是不同问题。
- 老师提出的“统一模型在四个 datasets 上与各自模型可比”是有条件的 merit 示例。现有 HF/KAUH diagnostic 不能直接证明这一点；是否扩大该 claim 需核对 native tasks、可比性与实际证据。
- 不写“所有 datasets 都失败”“所有 datasets 都改善”或宽泛 adaptive framework，除非相应结果与对照确实支持。

**保留的工作版本（供这轮讨论修改）**

Working title：Eligibility-Aware Hierarchical Task Alignment for Heterogeneous Respiratory Sound Learning

RQ：Does label-availability-aware hierarchical task alignment provide value beyond matched independent-head and single-dataset training when jointly learning ICBHI cycle-level and SPRSound event-level respiratory-sound tasks while preserving native evaluation?

Gap：Cross-dataset respiratory-sound learning lacks a controlled way to share partially overlapping respiratory attributes without converting unavailable labels into negatives or discarding dataset-native prediction units and metrics.
