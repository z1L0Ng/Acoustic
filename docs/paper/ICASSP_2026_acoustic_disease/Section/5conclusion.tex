\section{Conclusion}
\label{sec:conclusion}
We studied shared respiratory attributes while retaining dataset-native
tasks. Acoustic differences persisted within compatible labels after common
input preparation. In the benchmark controls, retaining fine SPRSound
annotations improved attribute discrimination and ICBHI Score. Source
comparisons and the HF-supervision case showed task-dependent gains and
costs. Native heads with matched C/W auxiliary supervision exceeded the
two-level reference in the single-seed comparison. The evidence supports
using available fine annotations while evaluating classification interfaces
separately, with conclusions bounded by the studied corpora, selection
protocols, and number of runs.
