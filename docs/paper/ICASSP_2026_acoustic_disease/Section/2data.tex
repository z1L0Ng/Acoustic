\section{Datasets and Acoustic Characteristics}
\label{sec:data_alignment}

\subsection{Datasets and Study Roles}
Core training uses ICBHI cycles and SPRSound events. ICBHI provides
4,142/2,756 train/test cycles in its official recording split, labeled
Normal, Crackle, Wheeze, or Both\cite{rocha2019icbhi}; the split is not
strictly patient-held-out. Both denotes C/W co-presence within a cycle.
SPRSound has seven event labels, while BioCAS2022 Task1-1 evaluates
Normal/Adventitious classification on 1,429 inter-subject test events
\cite{zhang2022sprsound}.

HF\_Lung\_V1 provides 7,809 source-training and 1,956 source-test recordings
of 15~s, with timed phase and adventitious-sound labels\cite{hsu2021hflung}.
Source-training data support a separate auxiliary-supervision study;
source-test data evaluate attributes. KAUH supplies external evaluation:
336 recordings from 112 patients, each with Bell, Diaphragm, and Extended
(B/D/E) filter versions\cite{fraiwan2021kauh}.

\subsection{Acoustic Cues and Annotation Granularity}
\label{sec:acoustic_characteristics}
Figure~\ref{fig:dataset_characteristics} characterizes the common 5-s
inputs defined below. Globally centered copies provide digital level
$20\log_{10}(\mathrm{RMS})$ in dBFS, referenced to full-scale amplitude 1,
not calibrated sound pressure. Spectral descriptions use 4-kHz analysis
copies and Welch power spectra\cite{welch1967spectra} with 1-s Hann windows,
50\% overlap, and a 4,000-point FFT. Centroids are power-weighted frequency
means within 80--2000~Hz; this restriction does not filter model inputs.

Descriptors are median-aggregated within recording and then patient/date
group, including KAUH filter versions within patient. The overview uses
ICBHI, SPRSound train+inter events, HF source-test windows, and all KAUH
recordings: 561 groups in total. Only ICBHI/SPRSound are compared within
compatible classes. Their class medians retain ICBHI--SPRSound level
differences of 25.13--29.11~dB and centroid differences of
$-68.38$ to $-28.95$~Hz. Both has only 10 SPRSound patient groups.
These source-associated differences motivate testing supervision and
native readouts without assuming acoustically interchangeable datasets.

\subsection{Annotation Alignment and Input Preparation}
\label{sec:annotation_alignment}
Shared targets $(a,c,w)$ encode abnormality, Crackle, and Wheeze.
ICBHI specifies all three; SPRSound merges Coarse/Fine Crackle, while
Rhonchi/Stridor supervise only A. Unsupported core targets are masked.
For Table~\ref{tab:native_results}, ICBHI subtraining contains
3,636/2,880/3,174 cycles at seeds 0/1/42, all supporting A/C/W.
Each SPRSound run uses 5,219 events; the same 49 events (0.94\%) lack
supported C/W targets. HF maps D to C and supplies no A target
(Section~\ref{sec:hf_method}).

KAUH prediction uses N, C/I~C, E~W/I~E~W, and I~C~E~W as Normal,
Crackle, Wheeze, and Both. Excluding Crep, Bronchial, and I~C~B leaves
86 compatible patients; the acoustic overview retains all 112.

Recordings are converted to mono 16~kHz and edge-faded before native-unit
extraction. ICBHI/SPR units and KAUH recordings longer than 5~s are
front-truncated; otherwise they are repeated/truncated to 5~s with a final
fade. HF uses consecutive [0,5], [5,10], and [10,15]~s windows.
Patient identities are retained; HF uses recording-date proxies.
