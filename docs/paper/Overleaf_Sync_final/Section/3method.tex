\section{Method}
\label{sec:method}
\subsection{Native Heads with Shared Attribute Supervision}
\label{sec:annotation_alignment}
\label{sec:native_readouts}
For an input ($x_i$) prepared as in Section~\ref{sec:acoustic_characteristics}, the shared BEATs encoder~\cite{chen2023beats,gemmeke2017audioset} produces tokens $H_i\in\mathbb{R}^{T_i\times D}$, where $T_i$ is the token count and $D=768$ (Fig.~\ref{fig:method_overview}). We average these tokens and apply a linear $D\to d$ projection to obtain $h_i\in\mathbb{R}^{d}$, with $d=256$. Dataset-specific linear heads predict $\boldsymbol q_i^{(s)}=\mathrm{softmax}(U_sh_i+v_s)$, where $s\in\{I,S\}$ denotes ICBHI or SPRSound. Two shared linear heads predict crackle (C) and wheeze (W) probabilities $p_{ik}=\sigma(W_kh_i+b_k)$, $k\in\{c,w\}$, where $\sigma$ is the sigmoid function.

The ICBHI and SPRSound heads have four and two outputs, respectively, and select the class with the highest predicted probability. Shared \texttt{C-W} supervision guides the representation used by both heads without requiring the native labels to share an output space~\cite{caruana1997multitask}. SPRSound's Rhonchi/Stridor (R/S) labels supervise its native abnormal class but do not specify \texttt{C-W} presence.

For external evaluation, we use the fixed ICBHI native head. HF test uses the maximum $P(W)+P(Both)$ across three consecutive windows per recording as a proxy score for Wheeze/Rhonchi/Stridor versus Other. This evaluates transfer to a broader target than Wheeze presence alone. For KAUH, we average $1-P(N)$ across each patient's recordings from different filter versions and predict Abnormal above 0.5, with ties selecting Normal.

\subsection{Annotation-Aware Joint Training}
\label{sec:joint_supervision}
\label{sec:hf_method}
Each annotation supplies a native target $t_i$ and attribute targets $y_{ik}$ with masks $m_{ik}$, where $m_{ik}=1$ only for supported attributes~\cite{shi2021marginal,zhou2022unknown,cole2021singlepositive}. ICBHI and SPRSound provide \texttt{C-W} supervision where their labels support it; SPRSound's Rhonchi/Stridor events contribute only to the native loss. For a single-dataset batch $B$, let $B_k=\{i\in B:m_{ik}=1\}$, $k\in\{c,w\}$. We combine native classification and shared attribute supervision:
\begin{equation}
\mathcal L_{\rm cls}(B)=\frac{1}{3}\bigl(
\mathcal L_{\rm native}(B)+\mathcal L_c(B)+\mathcal L_w(B)\bigr),
\label{eq:classification_loss}
\end{equation}
where $\mathcal L_{\rm native}$ is mean cross-entropy between $\boldsymbol q_i^{(s)}$ and $t_i$, and $\mathcal L_k=|B_k|^{-1}\sum_{i\in B_k}\mathrm{BCE}(p_{ik},y_{ik})$ is mean binary cross-entropy over supported labels, set to zero when $B_k$ is empty. LSAA w/o C+W removes $\mathcal L_c$ and $\mathcal L_w$ while retaining the $1/3$ native-loss weight.

Patient regularization uses a separate attention projection $Z_i=\mathcal G(H_i)\in\mathbb{R}^{D}$ and the losses from Patient-Aware Feature Alignment (PAFA)~\cite{jeong2025pafa}. Within each core-dataset batch, patient cohesion-separation loss (PCSL) promotes within-patient cohesion and between-patient separation; global patient alignment loss (GPAL) limits the dispersion of patient feature means. Both regularize the shared encoder.

The objective combines native and attribute supervision, patient regularization with optional HF supervision:
\begin{equation}
\mathcal L=\mathcal L_{\rm cls}
 +\lambda_p\mathcal L_{\rm PCSL}
 +\lambda_g\mathcal L_{\rm GPAL}+\lambda_{\rm HF}\mathcal L_{\rm HF},
\label{eq:total_objective}
\end{equation}
with $\lambda_p=50$, $\lambda_g=5\times10^{-4}$, and $\lambda_{\rm HF}=0$ for LSAA or $0.25$ for LSAA w/HF. HF's D labels denote crackles~\cite{hsu2021hflung}. HF train windows are eligible when they overlap D, Wheeze, Rhonchi, or Stridor annotations. Their \texttt{C/W} targets indicate D/Wheeze overlap, respectively; missing D/Wheeze annotations within eligible windows are treated as negatives. Thus, R/S-only windows have $(C,W)=(0,0)$, whereas SPRSound R/S events leave \texttt{C/W} masked. Phase-only and unannotated HF windows are excluded. $\mathcal L_{\rm HF}$ averages the \texttt{C/W} binary cross-entropies over eligible windows.

We jointly fine-tune the encoder and heads. Each core epoch contains 326 single-dataset batches of 32 units, equally divided between ICBHI and SPRSound; samples are shuffled and repeated as needed. Training uses Adam (learning rate $5\times10^{-5}$, weight decay $10^{-6}$), cosine decay, and exponential moving average (EMA) parameter smoothing with coefficient 0.5, for at most 50 epochs, without SpecAugment or mixup. We retain the subtraining partitions from fivefold stratified patient-group splits within the official training sets and use run seeds 0/1/42. For benchmarking, we follow the checkpoint-selection approach in prior released ICBHI implementations~\cite{bae2023patchmix,jeong2025pafa}, selecting checkpoints by official-test Score. Training stops after ten epochs without improvement in this selection Score; ties retain the earlier checkpoint.
