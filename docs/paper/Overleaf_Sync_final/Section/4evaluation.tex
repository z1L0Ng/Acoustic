\section{Evaluation}

\subsection{Experimental Setup}
\label{sec:protocol}
ICBHI cycles and SPRSound events train CHORD; evaluation uses
the official ICBHI split (not strictly patient-held-out)\cite{rocha2019icbhi}
and SPRSound inter-subject test set. Native inputs use 5-s front
truncation or repetition with boundary fading.
HF adds optional source-train C/W supervision; source-test evaluation
covers 957 eligible recordings. Each supplies three 5-s windows.
D/W/Rhonchi/Stridor overlap defines eligibility: absent C/W labels are
treated as negatives within eligible windows; gap, empty, and phase-only windows
are excluded. KAUH provides external binary balanced accuracy (BA) on
86 Normal/Crackle/Wheeze/Both patients.

Core controls share encoder initialization, partitions, and maximum
update budgets; source exposure differs. Checkpoints use ICBHI test Score
except SPRSound-only uses SPR inter Score; C/W thresholds use core validation.
Core results use seeds 0/1/42 and PAFA weights\cite{jeong2025pafa};
HF-on uses $\lambda_{\rm HF}=0.25$. External evaluation fixes models
and thresholds.

\subsection{Joint Learning and Transfer}
\label{sec:native_results}
Joint training with CHORD improves ICBHI Score by 3.39 percentage points
(pp) and reduces SPRSound Score by 2.13 pp relative to their respective
single-source models (Table~\ref{tab:native_results}). Direct cross-source
application performs substantially worse, supporting joint supervision
for both native tasks under this protocol. Frozen-encoder references
provide adaptation context: CHORD exceeds their ICBHI Scores, while the
strongest retain higher SPRSound performance.

HF/KAUH results quantify transfer through the same attributes at recording
and patient levels, without external tuning. Comparisons with single-source
external models remain unavailable.

\subsection{Supervision and Readout Ablations}
\label{sec:ablations}
\label{sec:fine_supervision}
\label{sec:readout_analysis}
\label{sec:transfer}
Fine labels benefit SPRSound's binary task under the evaluated recipe.
Coarse SPR removes its C/W supervision and calibration, retaining $L_A/3$.
Fine labels improve C/W AUROC and both native Scores in all three seeds
(Table~\ref{tab:ablations}(a)). The SPR mean gain includes an all-Normal
Coarse seed 0; seeds 1/42 gain 4.57/0.15 pp. This comparison also changes
classification-loss strength relative to PAFA.

Direct C/W bypasses A gating on fixed ICBHI scores: $Sp$ falls 6.80 pp
while $Se$ rises 5.04 pp. Native + C/W retrains the model with dataset-specific
heads and matched C/W supervision, gaining 2.50 pp on ICBHI with only a
$-0.05$-pp C/W AUROC change. Attribute discrimination and task accuracy
therefore need separate assessment. Two-level decoding provides explicit
A/C/W readouts; native heads can improve task accuracy.

HF supervision raises SPRSound Score but lowers ICBHI Score in both
pairs (Table~\ref{tab:ablations}(b)). HF AUROC and KAUH BA change direction
across pairs: added mapped labels have task-dependent effects.
