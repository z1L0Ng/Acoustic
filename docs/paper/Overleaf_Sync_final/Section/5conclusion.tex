\section{Conclusion}
\label{sec:conclusion}
In this work, we presented LSAA, which combines shared acoustic attribute supervision with dataset-specific native heads to learn from heterogeneous respiratory sound annotations. Shared C/W supervision improves mean SPRSound performance and transfer to HF and KAUH, with a small ICBHI performance decrease relative to native-task training alone. These results show that fine-grained annotations can support learning beyond the labels required by a native task. Additional HF supervision does not uniformly improve performance, emphasizing the need to assess shared supervision against each prediction target. Future work will explore a broader set of shared acoustic attributes and how to combine their supervision to better support each task.
