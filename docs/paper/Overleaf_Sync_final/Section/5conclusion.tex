\section{Conclusion}
\vspace{-3mm}
\label{sec:conclusion}
We presented LSAA, which shares acoustic attribute supervision across heterogeneous respiratory sound datasets while preserving distinct native tasks. We find that retaining fine-grained annotations benefits both native tasks despite SPRSound's binary output. Native heads with C/W supervision achieve higher mean task and transfer performance than explicit attribute readouts, with similar SPRSound C/W discrimination. Evaluation on HF and KAUH further shows that additional supervision need not improve transfer.
