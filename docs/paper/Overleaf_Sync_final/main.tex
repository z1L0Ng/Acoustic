\begin{abstract}
Public respiratory sound datasets carry different levels of annotation detail and are labeled for different classification or prediction tasks. Mapping these annotations to a common target can discard sound-type distinctions that remain useful to another task. We propose \textsc{LSAA} (\underline{L}earning \underline{S}hared \underline{A}coustic \underline{A}ttributes), a joint learning framework that shares acoustic supervision while preserving native tasks. \textsc{LSAA} learns a shared representation from ICBHI cycles and SPRSound events using native task losses with auxiliary crackle (\texttt{C}) and wheeze (\texttt{W}) supervision. Each annotation contributes only to the attribute losses it supports. Dataset-specific heads preserve ICBHI four-class cycle classification and SPRSound binary event classification, allowing fine-grained annotations to guide learning beyond the label detail required by the native output. We evaluate fixed-model transfer on HF Lung (HF) testing set and KAUH. Across three seeds, adding \texttt{C-W} supervision improves SPRSound Score by \textbf{1.93 points}, HF AUROC by \textbf{7.16 points}, and KAUH balanced accuracy by \textbf{2.32 points}, with a 0.20 points ICBHI Score decrease relative to native-task training alone. These results support sharing fine-grained acoustic supervision across heterogeneous annotations while retaining task-specific prediction interfaces.
\end{abstract}
