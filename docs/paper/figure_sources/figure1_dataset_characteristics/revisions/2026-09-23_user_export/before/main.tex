\begin{abstract}
Public respiratory sound datasets carry different levels of annotation detail and are labeled for different classification or prediction tasks. We propose \textsc{LSAA} (\underline{L}earning \underline{S}hared \underline{A}coustic \underline{A}ttributes), a joint learning framework that shares acoustic supervision while preserving native tasks. \textsc{LSAA} learns a shared representation from ICBHI cycles and SPRSound events using native task losses and auxiliary crackle (C) and wheeze (W) supervision. Dataset-specific heads produce native predictions, allowing fine-grained sound-type annotations to guide learning even when the output is binary. We evaluate fixed-model transfer on HF Lung (HF) test recordings and KAUH. Across three seeds, adding C/W supervision improves SPRSound Score by 1.93\%, HF AUROC by 7.16\%, and KAUH balanced accuracy by 2.32\%, with a 0.20\% ICBHI Score decrease. These results support shared fine-grained supervision for native prediction and transfer.
\end{abstract}
